# 数据来源

当前收录 10,000 篇 arXiv 论文，包含 RAG、智能体、大模型推理、多模态、图像／视频生成、具身智能、高效训练与推理、代码生成与软件工程、大模型安全与对齐、AI for Science 十个主题，各 1,000 篇。

数据来源、检索范围、采集时间及抽样记录见 [sources.json](../data/sources.json)。原始文献保存在 [raw_papers.jsonl](../data/raw_papers.jsonl)，保留原有标题、摘要、作者、分类、时间、版本和来源链接。

已获得的作者关键词及其来源一并保存在文献中，未找到时保留状态。关键词不拼入检索文本。原始文件保存的是摘要级文献数据，全文通过论文链接访问。

2026-10-17 第一批新增高效训练与推理、代码生成与软件工程各 1,000 篇，沿用 2021–2025 年首次提交范围。通过 arXiv 官方 API 按细分方向检索，依据标题、摘要中的模型语境和分类筛选，再按细分方向轮流选取。按不含版本号的 arXiv ID、规范化标题、规范化摘要，排除与原库及新增主题之间的重复；原 6,000 篇记录保持不变。

新增高效训练与推理语料涵盖量化、蒸馏、高效微调、解码与部署、缓存与剪枝；代码语料涵盖生成、修复、测试、代码分析及其他软件任务。候选来自每个查询最多最近 1,000 条匹配，按固定种子排序选取，具体查询、筛选规则和实际分布记录在 sources.json；这些分组是自动筛选结果，不是逐篇人工标注。新增 2,000 篇未补采作者关键词，保留 null 和 pending（尚未采集）状态。

2026-10-17 第二批新增大模型安全与对齐、AI for Science 各 1,000 篇，同样使用 2021–2025 年范围。安全方向涵盖越狱、提示注入、偏好对齐、安全评估、隐私与遗忘；科学方向涵盖蛋白质、分子与药物、材料、物理模拟和数学。按标题主题短语与摘要模型语境筛选；科学论文允许来自物理、生物等非 cs 分类。安全方向进一步排除缺乏安全／隐私主题的纯记忆能力研究和图像生成偏好研究。

第二批按同样的 arXiv ID、规范化标题、规范化摘要规则，与原 8,000 篇及新增主题交叉去重。原 8,000 篇记录保持不变。两批共新增 4,000 篇均未补采作者关键词。具体细分数量、查询和固定种子选取规则见 sources.json。
